# Python Caesar Cipher Tool (Encrypt & Decrypt) 🔐

A simple, clean Python command-line application that implements the classic Caesar Cipher algorithm. This project allows users to both encrypt text (shifting letters forward) and decrypt text (shifting letters backward) using a custom shift number.

This project is part of my ongoing journey learning Python and building practical command-line tools.

## Features ✨
* Two Separate Scripts: 
  * encrypt.py: Takes your message and a shift number to securely encode your text.
  * decrypt.py: Takes the encrypted message and the exact same shift number to restore it back to the original text.
* Case Sensitivity: Preserves the original uppercase and lowercase formatting of the letters.
* Special Characters: Ignores spaces, numbers, and punctuation, leaving them untouched in the output.

## How to Run 🚀
1. Make sure you have Python installed on your system.
2. Clone this repository or download the files.
3. To Encrypt a message:
